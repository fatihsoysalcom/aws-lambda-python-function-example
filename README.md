# AWS Lambda Python Function Example

This Python script demonstrates a basic AWS Lambda function handler. It shows how to receive an event, process it, and return a structured response, which is a core concept for the AWS Developer Associate certification.

## Language

`python`

## How to Run

This code is designed to be deployed as an AWS Lambda function. To run it locally for testing, execute the script using `python main.py`.
